# RAVIN Travel Landing Page

Persian RTL travel discovery and booking landing page built with HTML, CSS and Vanilla JavaScript.

## Prototype scope
Responsive landing page, travel search UI, destination discovery, editorial sections, FAQ and demo forms. Booking, inventory, payment, authentication and newsletter delivery are not connected to backend services or supplier APIs.

## Run locally
Open `index.html` in a modern browser. Review placeholder contact details and domain metadata before production.

Destination artwork is AI-generated; verify landmark accuracy before commercial use.
